# 南京旅行攻略（示例语料，票价/开放时间请出行前核实）

## 城市简介
南京，六朝古都、十朝都会，历史底蕴深厚，民国风情与山水城林并存。核心看点：钟山风景区（中山陵、明孝陵）、总统府、夫子庙秦淮河夜景、南京博物院。市区景点集中在地铁沿线，3 天可覆盖核心内容，适合人文爱好者、亲子与摄影。

## 必去景点

### 中山陵（钟山风景区）
- 地址：玄武区紫金山南麓；地铁 2 号线苜蓿园站换乘景区接驳车
- 门票参考：免费（需预约），景区接驳车另收费
- 简介：孙中山先生陵寝，392 级台阶的中轴线气势恢宏。从博爱坊一路向上，秋天梧桐大道极美。建议上午前往，游览约 2-3 小时。

### 明孝陵
- 地址：玄武区紫金山南麓（与中山陵相邻）
- 门票参考：70 元左右
- 简介：明太祖朱元璋陵墓，世界文化遗产。神道石像生是精华，秋天银杏与红枫非常出片。可与中山陵安排同一天，步行或乘景区车衔接。

### 总统府
- 地址：玄武区长江路 292 号；地铁 2/3 号线大行宫站
- 门票参考：35-40 元
- 简介：近代史浓缩地：太平天国天王府、两江总督署、民国总统府三重叠。游览约 2 小时，建议配讲解了解民国历史。

### 夫子庙·秦淮河
- 地址：秦淮区贡院街；地铁 3 号线夫子庙站
- 门票参考：街区免费；科举博物馆、瞻园等单点购票
- 简介：南京最经典的夜游地。白天逛江南贡院、乌衣巷，晚上乘画舫游秦淮河看灯火。周边小吃密集，注意游客多、正餐建议避开主街。

### 南京博物院
- 地址：玄武区中山东路 321 号；地铁 2 号线明故宫站
- 门票参考：免费（需提前公众号预约）
- 简介：中国三大博物馆之一，民国馆是网红打卡点。镇馆之宝有银缕玉衣等。建议预约上午时段，逛 3 小时以上。

### 玄武湖
- 地址：玄武区；地铁 1 号线玄武门站
- 门票参考：免费
- 简介：城中湖，环湖 9 公里，可散步、骑行、划船。从解放门可上明城墙俯瞰湖景。傍晚看日落很舒服。

### 鸡鸣寺
- 地址：玄武区鸡鸣寺路；地铁 3/4 号线鸡鸣寺站
- 门票参考：10 元（含 3 支香）
- 简介：南朝四百八十寺之首。每年 3-4 月樱花大道是南京最热门打卡地。古生物博物馆在旁边，可顺路。

## 特色美食
- 盐水鸭、板鸭（桂花鸭）
- 鸭血粉丝汤（小潘记、回味）
- 牛肉锅贴（李记清真馆）、鸡鸣汤包
- 皮肚面、赤豆元宵、梅花糕、糖芋苗

## 交通建议
- 大交通：高铁南京南站（1/3 号线进城）；机场为禄口机场，地铁 S1 号线进城
- 市内：地铁 1-4 号线覆盖主要景点；钟山风景区需换乘景区接驳车
- 景点间：中山陵/明孝陵同属钟山，建议半天集中；总统府、博物院、玄武湖都在市区东侧，可串联

## 推荐行程节奏（3 天人文版）
- 第 1 天：中山陵 → 明孝陵（钟山一日）→ 傍晚玄武湖
- 第 2 天：总统府 → 六朝博物馆 → 南京博物院 → 晚上夫子庙秦淮河夜游
- 第 3 天：鸡鸣寺 → 明城墙台城 → 老门东觅食 → 下午返程
